# Gym Log

Offline-first workout tracker for Android (Expo / React Native). See `CLAUDE.md` for architecture and
`ROADMAP.md` for the plan.

## Install / update on your phone

Scan this QR code with the phone camera. It always downloads the newest APK from
[the latest release](https://github.com/chiefabs6-ops/Gym-Application-/releases/latest).
Open the download and tap **Update** (Android may ask once to allow installs from your browser).
Updating keeps all your workouts.

![Update QR code](docs/update-qr.png)

Direct link: https://github.com/chiefabs6-ops/Gym-Application-/releases/latest/download/gym-log.apk

Publishing a new version: see `docs/release-apk.md` → "Publishing an update".
