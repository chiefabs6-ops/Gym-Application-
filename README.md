# Gym Log

Offline-first workout tracker for Android (Expo / React Native). See `CLAUDE.md` for architecture and
`ROADMAP.md` for the plan.

## Get the app (Android)

Scan this QR code with your phone camera, or open the link on your phone. It always downloads the newest version.

![Download QR code](docs/update-qr.png)

**Download:** https://github.com/chiefabs6-ops/Gym-Application-/releases/latest/download/gym-log.apk

First install:
1. Open the downloaded `gym-log.apk` (from the browser's downloads or the notification).
2. Android asks to **allow installs from this source** (your browser). Allow it, then go back.
3. Tap **Install**. If Play Protect warns about an unknown app, tap **More details → Install anyway**.
   (The app isn't on the Play Store, so Android shows this for any app installed this way.)

No account needed: everything stays on your phone. Android only, no iPhone version.

Updating later: in the app go to **Settings → About → Check for update**, or scan the QR code again.
Updating keeps all your workouts.

Publishing a new version: see `docs/release-apk.md` → "Publishing an update".
